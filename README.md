# Svxlink-Touch-Release
Download and Install SvxLink-Touch for Android

SvxLink-Touch is an Android application that connects directly to a compatible SvxReflector server, allowing authorised amateur radio operators to communicate using their Android mobile phone.

The application supports touchscreen Push-to-Talk (PTT), Bluetooth audio devices, and compatible Bluetooth PTT buttons.

Requirements

Android 8.0 or later

64-bit ARM Android phone

Wi-Fi or mobile internet connection

Valid SvxReflector server details, callsign and password

Step 1 — Download the application

On your Android phone, open your web browser and visit the download link below:

Download SvxLink-Touch-Android v0.2 - 

The APK file will be downloaded to your phone, usually into the Downloads folder.

If your browser asks whether you wish to download the file, confirm the download.

Step 2 — Allow installation

Because SvxLink-Touch is distributed directly rather than through the Google Play Store, Android may request permission to install applications from your browser or file manager.

If prompted:

Tap Settings.

Find Install unknown apps.

Select the application used to open the downloaded file, such as Chrome or My Files.

Enable Allow from this source.

Return to the downloaded APK.

Some Samsung phones may also have an Auto Blocker setting that prevents installation from outside official app stores. Follow your phone's security instructions if installation is blocked.

Only install the APK obtained from the official G4NAB GitHub release.

Step 3 — Install SvxLink-Touch

Open your phone's Downloads folder.

Tap SvxLink-Touch-Android-v0.1.apk.

Select Install.

When installation finishes, tap Open.

SvxLink-Touch will now be available in your phone's application list.

You may disable Allow from this source again after installation.

Step 4 — Configure the application

Open SvxLink-Touch and enter the connection details supplied by your SvxReflector administrator:

SvxReflector server address and port

Authorised callsign

Reflector access password

Preferred talkgroup and monitored talkgroups, where applicable

Save the configuration and connect to the reflector.

Allow microphone and Bluetooth permissions when requested, as required by the features you intend to use.

Step 5 — Using Push-to-Talk

For touchscreen operation, select On-screen PTT in the application settings.

For a compatible Bluetooth PTT button, use Scan for Bluetooth PTT, select the button and allow the application to verify and save its details. Once configured, the saved button can be used without repeating the initial discovery process.

The application supports Press and hold and Toggle PTT operating modes.

Important: Select an authorised talkgroup before transmitting. TG0 is standby and does not permit transmission.
